## 恢复与复跑

```bash
python3 tempo/tools/piperx_direct/launch.py \
  --project /path/to/ma800/tempo \
  --baseline /path/to/inputs.json \
  --tempo-repo /path/to/configured/TEMPO \
  --name clockwise_direct_repro \
  --gpus 1,2 --micro-batch 16 \
  --publisher-python /path/to/modelscope/.venv/bin/python
```

MA800 训练环境沿用配置好的 Transformers 补丁、π0.5 base、RGB/state/action 和 SAM2 缓存。ModelScope 凭据通过 `token_file` 指向本机文件。复跑时按同一 split 和 norm 准备缓存。

## 夹爪输出与归位

策略动作的第 7 维经分位反归一化得到绝对开口宽度。TE 对同一时刻的合格预测按权重合并开口值。实机命令使用配置中的 1.0 N 力参数，超出 0–100 mm 的策略目标会被拒绝。

勾选归位并确认本轮实机执行后，机械臂先低速到达关节归位点，随后夹爪移动至安全配置允许的最大开口，当前为 100 mm。实测开口达到配置的 1 mm 到位容差后才开始策略执行。归位超时或取消会结束本轮启动。模拟 SDK 覆盖了归位顺序、全开目标、反馈超时与取消。
