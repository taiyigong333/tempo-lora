## 同样本核对

以相同 RGB、状态、SAM2 张量和时间索引分别经过实际 MA800 加载器和 4090 部署变换。13 个时间点覆盖首帧、半段补零、第 90 帧前后和窗口滚动。两路 RGB 历史 `[t-20, t-10, t]`、缺失相机掩码、7 维实测 state（六关节 rad 与夹爪开口 m）、分位数归一化后状态、文本及状态离散 token、截至 t-1 的 90 帧 state 的 10 段均值及掩码、SAM2 token 排布均逐元素一致。归一化动作经部署逆变换后恢复绝对关节角和夹爪开口，最大误差分别为 8.94×10⁻⁸ rad 和 0 m。

训练使用实测下一帧 state 作为动作监督、训练期图像增强和 u_t 目标。部署由解码器生成动作、使用实时相机 RGB，并按模式使用调度；VLASH 额外将预计接管状态用于当前条件，历史仍取实测反馈。离线数据经过 JPEG 和 H.264 编解码，线上维持实时 RGB。抽样中训练 MP4 解码相对编码前 RGB 有 1.47/255 的像素平均绝对差，代表采集存储链路差异。

## 部署修复

- 相机缩放采用训练转换器的等比尺寸向下取整、双线性缩放和居中黑边。从三个批次抽查双相机 48 帧，旧面积插值让 34.52% 的通道值改变，单通道最大差 65/255，修复后与同原始帧的训练转换器逐像素一致。
- 相机时间网格改为在收到网格前后实测帧后，取绝对时间差最小的帧，同距取前帧，最大允许 100 ms，复用既有等待和双相机偏差保护。三个原始片段共 338 个网格，旧逻辑与训练选帧不同 151 次，平均时间偏差由 19.22 ms 降至 11.89 ms。在线硬件最邻近选帧可能等待后一帧到达；现场闭环延迟与抓取表现待实机确认。
- SAM2 时间位置编码使用与训练缓存相同的 16 帧指针跨度。所有 289 个训练片段均足以覆盖此跨度，在线仍只访问已经收到的帧。MA800 原地抽查三段各 24 帧，旧算法最大特征误差 0.96045，修复后 72 帧与缓存逐元素一致。
- step5000 的 SAM2 融合门和输出投影权重、偏置均为零。双零初始化让这条残差路径的两处梯度都为零。4090 固定噪声回放的修复前后输出动作相同。现有权重中的 SAM2 分支没有动作贡献，此训练问题需通过修正初始化并重新训练解决。
