# 全量TEMPO推理优化验证

2026-11-15，北京时间。

## 目标与对照基准

降低全量微调模型在线推理延迟。固定模型权重、30步动作块、10次去噪、实测反馈历史、归一化和时间锚点，以优化前8002编译服务为数值参考。

既有编译路径相对eager的历史对照最大差异约1.14度关节与0.96毫米夹爪。本轮核验新增执行优化与该编译参考路径的一致性。

## 采用的两项修改

### 缺失相机省算

当前PiperX提供head和left_wrist，第三路right_wrist为全mask空槽。新增skip_missing_cameras执行选项，跳过该路视觉编码，保留其token位置和mask。空槽采用已编码视觉特征的dtype，保证BF16拼接行为与参考路径一致。

### SAM2按需读取融合特征

SAM2记忆写入依赖当前骨干特征与全帧mask，每帧都会执行并按原规则保留历史。一次请求仅融合最后一帧的SAM2读出，因此批内中间帧直接更新记忆，最后一帧再执行记忆注意力与8×8池化读出。新增latest_sam_features_only选项作用于SAM2并行批处理路径。

## 数值验证

固定录制图像、状态和噪声，先验证9例59帧序列，覆盖1、2、3、4、8、16帧反馈批次及3例RTC引导。再做3轮交替顺序的配对基准，共27组输出对照。

- 动作逐元素一致，最大绝对差0。
- 每次推理采用的SAM2 tokens逐元素一致。
- 完整序列结束时的全部SAM2记忆，包括特征、位置编码和对象指针，逐字节哈希一致。
- 新增优化专项11项通过，复用服务端回归38项通过。另1项旧训练目录配置发现测试被排除。

## 同机配对耗时

共享GPU训练任务结束后，在同一进程内交替切换参考与优化执行选项，固定输入和噪声。统计27次推理的混合原生/RTC样例。

| 指标 | 参考路径 | 两项优化 |
|---|---|---|
| P50 | 186.04 ms | 143.28 ms |
| P95 | 324.81 ms | 222.76 ms |
| 8帧原生样例P50 | 196.85 ms | 141.94 ms |
| 16帧原生样例P50 | 289.76 ms | 186.37 ms |

总体P50降低22.98%，P95降低约31.4%。同一进程、相同输入与交替执行顺序使本组结果能区分代码优化收益与GPU训练结束的收益。

此前仍有训练负载时，原生20秒候选调度完成，往返P50约263ms、P95约311ms，TE和RTC触发时效条件。GPU负载仍会影响持续控制。

## 持续调度验证

候选8003服务使用真实有线网络、30Hz重复录制反馈、正常InferenceRun调度器与模拟机器人。

| 模式 | 时长 | 结果 | 往返P50 | P95 |
|---|---|---|---|---|
| 原生 | 20秒 | 完成，121批602帧 | 154.72 ms | 162.62 ms |
| TE | 20秒 | 完成，134批597帧，601个目标 | 148.81 ms | 157.44 ms |
| RTC | 20秒 | 完成，99批597帧，98次前缀引导 | 201.09 ms | 220.02 ms |

全部自动验证机器人控制命令0。当前0.5秒时效条件、控制频率与反馈连续性约定沿用既有配置。

正式8002复测原生20秒完成，121批603帧，P50为154.66ms、P95为163.07ms。TE60秒完成，403批1800帧、1801个规划目标，P50为148.88ms、P95为156.06ms。

正式RTC首次20秒目标测试，在61批360帧、370个规划目标后触发时效停止，约运行12秒，P50为199.54ms、P95为209.96ms。候选RTC20秒通过，正式RTC仍存在时效停止，需继续现场验收。

正式日志位于PiperX client/logs/tempo_full/optimization/official_realtime/，汇总为同级official_realtime_report.json。单独RTC60秒目标复测约11秒时同样停止，53批321帧、331个规划目标，P50为203.16ms、P95为224.09ms，另存为official_rtc60_report.json。两次正式失败结果均保留，RTC持续运行验收仍待完成。

## 其他候选的实验结果

前缀压缩样例最大关节差0.12852rad，夹爪差0.007267m。省去SAM2高分辨率投影的样例中，SAM2 tokens和记忆发生变化。两项候选的逐元素一致性条件未满足，正式部署采用上面的两项精确省算。
