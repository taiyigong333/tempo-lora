# 2026-11-08 正式训练执行优化

用户要求改善训练速度，保持batch16、梯度累积1次、全部393条轨迹、10000个优化器更新、3000步定期保存与W&B online。优化不减少相机、历史帧、训练模块或训练数据。

## 定位与修改

基线实测约5.85秒/步，GPU接近满载。联合VLM/专家前向同时被整段checkpoint与逐层checkpoint包裹，造成额外重计算；缺失右腕相机、prompt padding与整批无效历史仍以mask token参与联合Transformer。

新增兼容开关：

| model配置 | 默认值 | 作用 |
|---|---|---|
| compact_prefix | false | 仅删除整批均被屏蔽的prefix列，保留所有有效输入和部分样本有效的列 |
| checkpoint_joint_forward | true | 控制整段联合前向重计算 |
| joint_gradient_checkpointing | true | 控制联合Transformer逐层重计算，独立于视觉分支 |

prefix的attention boundary全为零，删除padding不改变有效token的旋转位置编号和注意力可见关系。原有默认配置保留旧执行路径。checkpoint恢复仅放行这三个执行开关变化，数据、动作语义、模型结构、batch、学习率和调度配置继续严格匹配。

程序先等待500步指标和完整best.pt，再暂停旧主进程，严格验证模型/优化器/scheduler均为500，保留step_00000500.pt及独立硬链接handoff_step500.pt，并原子维护latest。验证失败则继续旧进程，禁止从基座重来。验证成功后停止旧流水线，释放GPU，独占测量候选路径，从留出至少10%显存的成功候选中选最高吞吐者，再以同一run目录、W&B id、优化器、调度、随机状态与采样位置恢复。
